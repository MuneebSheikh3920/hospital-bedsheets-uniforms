HOSPITAL LINEN WEBSITE – kaise use karein
=========================================
1. Folder ko unzip karein, phir index.html par double click karein (browser mein khul jayegi).
2. WhatsApp number badalna: js/config.js kholein, WHATSAPP_NUMBER mein apna number likhein (923xxxxxxxxx).
3. Shop ka naam: js/config.js mein SHOP_NAME.
4. Bed sheet product edit / naya add karna: js/data.js (har product ek { ... } block hai).
5. Images badalna: images folder mein usi naam se apni photo rakh dein (jpg).
6. Menu / header / footer badalna: js/layout.js.

Folder structure:
  *.html   -> har page ki HTML (sirf structure)
  css/     -> base.css (sab pages) + har page ki apni css
  js/      -> config, data, layout, cards + har page ki apni js
  images/  -> saari images
